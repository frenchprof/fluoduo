# Dan's litmus test — permanent design rule (2026-07-02)

**Anything that, when removed, does not prevent the user from finding the
correct answer is REDUNDANT — remove it.** Applies to every learner-facing
surface: no section labels, context blurbs, grammar badges, icons,
explanations, or progress lines unless the learner literally cannot answer
without them. Minimalist is the strictest rule for everything.
