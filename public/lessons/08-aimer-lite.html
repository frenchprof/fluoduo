❤️ Aimer + le / la / les

Unité 2 · lite pilot — Mémo + 🎲 only

Aimer, adorer, détester + toute la catégorie

With verbs of preference (aimer, adorer, détester, préférer) you talk about the thing in general, so you use the definite article:

le+ nom masculin J'aime le sport.
la+ nom féminin J'adore la musique.
l'+ voyelle J'aime l'art.
les+ pluriel Je déteste les films d'horreur.
⚠️ Even in the negative, the article stays le / la / les — it does not become de (that's the partitive, for quantities):
J'aime le sport → Je n'aime pas le sport.  ·  J'adore l'art → Je n'adore pas l'art.
