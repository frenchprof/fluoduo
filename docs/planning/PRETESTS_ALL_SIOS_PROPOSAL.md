# FluoLingo — Pretest questions for the remaining SIOs (validation copy)

_Generated 2 Jul 2026. Format per Dan's minimalist rule — each question is exactly four things:
the **gapped sentence in French**, the **TTS** (always the full completed sentence, spoken on a
correct answer), the **intended meaning in English**, and the **choices**._

**How to read this:** the correct choice is in **bold**; the other three are distractors.
Question order and option order are randomised in the app on every activation, so no question
references any other. Guard-rails respected throughout: present + futur proche only, no
imperatives (imperative forms appear only as *wrong* distractors), *je voudrais / j'aimerais*
as fixed politeness.

Already live: SIO-031 (weather) and SIO-032 (city/country prepositions) — authored earlier.
Unit 0 SIOs use their own popup quizzes. Production SIOs (010/020/030/040/049/050) get no pretest.
